下面按**你可以直接逐条改 tex**的方式列。重点是“课程 final deliverable”标准：不需要把实验扩很多，但要让表述更稳、更像真实研究报告，避免 overclaim 和 AI 味。原文我基于你上传的 tex 来看。

## 1. Abstract 里的实验规模描述不准确

**位置：Abstract**

原文大意：

> On a 10-task sequential gridworld benchmark with 9 agent variants and 2 boundary modes...

**问题：**
正文 protocol 里主实验是 **10-task alpha + carryover**；reset vs carryover 是 **5-task pilot**。现在 abstract 容易让人以为你完整跑了 `10 tasks × 9 agents × 2 boundary modes`。

**建议改成：**

```tex
On a 10-task sequential gridworld benchmark under carryover boundary
conditions, supplemented by a 5-task reset-vs-carryover factorial study,
\hace{} agents achieve ...
```

或者更简洁：

```tex
On a 10-task carryover benchmark, with a complementary 5-task
reset-vs-carryover study, \hace{} agents achieve ...
```

## 2. Abstract 里的 “confirming orthogonal” 说太满

**位置：Abstract 最后一句**

原文：

```tex
Combining \hace{} with EWC addresses both viability and forgetting,
confirming the two failure modes are orthogonal.
```

**问题：**
“confirming orthogonal” 太强。你只做了 HACE+EWC 一个组合，最多说明二者可以部分分离，不足以证明完全正交。

**建议改成：**

```tex
Combining \hace{} with EWC improves both viability and retention,
suggesting that viability maintenance and forgetting mitigation are
partially separable axes in embodied CRL.
```

## 3. Introduction 里 “Conservation → Sprint” 例子和主实验不完全对应

**位置：Introduction，concrete example 段落**

原文：

```tex
An agent trained on \textsc{Conservation} ... transitions to \textsc{Sprint} ...
```

**问题：**
这个 transition 在 gamma 里有，但主实验 alpha 不是 Conservation → Sprint。作为 illustrative example 可以，但要说明它不是 main alpha 结果，否则读者会觉得你在暗示主实验里就有这个 transition。

**建议改成：**

```tex
As an illustrative transition, consider an agent trained on
\textsc{Conservation} ... moving to \textsc{Sprint} ...
```

或者直接换成 alpha 里真实的 transition，比如：

```tex
For example, an agent that completes \textsc{Collect Exit} or
\textsc{Detour} with little remaining energy may enter the next task
without enough resources to explore.
```

## 8. HACE 的 setpoint = energy cap 需要解释，否则 homeostasis 概念会被质疑

**位置：Homeostatic Drive Reduction**

原文：

```tex
where $\alpha = 1.0$ by default and $\setpoint = \energy_{\text{cap}}$.
```

**问题：**
如果 setpoint 是 energy cap，这更像“保持满能量”或“energy preservation shaping”，而不是传统意义上的中间稳态。不是错误，但需要主动说明。

**建议在这句后面加：**

```tex
In this benchmark, setting the homeostatic point to the energy cap makes
\hace{} a conservative energy-preservation signal: the agent is rewarded
for avoiding depleted boundary states rather than for merely maximizing
task reward.
```

如果想更严谨一点：

```tex
We use this instantiation because the central risk in our environments is
depletion-induced death; other domains may require intermediate or adaptive
setpoints.
```

## 13. Reset vs carryover 部分的 “same network weights” 是最大风险点

**位置：Reset vs Carryover subsection**

原文：

```tex
Crucially, the \emph{same network weights} produce these divergent outcomes---
the only difference is whether energy resets between tasks.
```

**问题：**
只有在你拿同一个 checkpoint 分别用 reset/carryover 初始 energy 做 evaluation 时，这句话才成立。
如果 reset 和 carryover 是两个条件分别训练出来的，那 weights 不一样，这句话就是硬伤。

**安全改法：**

```tex
Crucially, the task definitions, architecture, and training protocol are
held fixed; the key manipulation is whether energy is reset or carried
across task boundaries.
```

然后下一句改成：

```tex
This supports the interpretation that resource-state carryover, rather
than forgetting alone, drives the observed collapse.
```

如果你确实做了同一 checkpoint 的 counterfactual evaluation，可以写：

```tex
In a counterfactual evaluation using the same trained checkpoint, changing
only the boundary energy state produces divergent outcomes ...
```

但只有真的做了才能这样写。

## 49. “full 9-agent factorial design” 不准确

**位置：Appendix pilot**

原文：

```tex
full-scale 9-agent factorial design
```

**问题：**
9 agents 不是严格 factorial design，因为 A-I 不是所有因素完全交叉组合。比如 reward, EO, CRL, Seq 没有完整排列。

**建议改成：**

```tex
full-scale 9-agent comparative design
```

或者：

```tex
full 9-agent experimental suite
```
